# 🤖 دستیار هوش مصنوعی (AI Assistant)

یک دستیار هوش مصنوعی دسکتاپ مدرن، ماژولار و قابل توسعه نوشته‌شده با **Python**.

پشتیبانی کامل از فارسی و انگلیسی، ذخیره تاریخچه گفتگوها، مدیریت خطا و آماده برای افزودن قابلیت‌های پیشرفته.

**ساخته شده توسط امیرحسین بخشی**

---

## ✨ ویژگی‌ها

- رابط کاربری مدرن و زیبا با `customtkinter`
- گفتگو متنی با مدل‌های OpenAI و سرویس‌های سازگار (OpenRouter و ...)
- ذخیره و بازیابی خودکار تاریخچه گفتگوها
- پشتیبانی از پاسخ جریانی (streaming)
- مدیریت خطا، تایم‌اوت و قطع اینترنت
- تنظیمات امن از طریق فایل `.env`
- ساختار کاملاً ماژولار و آماده توسعه

---

## 🛠️ پیش‌نیازها

- Python 3.11 یا بالاتر
- کلید API از OpenAI یا سرویس سازگار

---

## 🚀 نصب و اجرا

```bash
# کلون پروژه
git clone https://github.com/Amirhosseinbakhshi2011/AI.git
cd AI

# ساخت محیط مجازی
python -m venv venv

# فعال‌سازی
# ویندوز:
venv\Scripts\activate
# لینوکس / مک:
source venv/bin/activate

# نصب وابستگی‌ها
pip install -r requirements.txt

# کپی فایل تنظیمات
cp .env.example .env
# بعد کلید API رو داخل .env بذار

# اجرا
python main.py
```
